# 更新记录

## 0.1.0-preview.16 — 2026-11-19（本机开发版，尚未发布）

- 完成会议优先显示主持结论；提案、互评及长文可折叠，展开选择按会议隔离并保留到本标签页刷新后。“只看本场”隐藏其他任务，保留返回入口和草稿。
- 显示本场真实墙钟耗时、各方等待和官方 CLI 可确认的本轮用量；网页用量明确未知，不将并行耗时相加或把会话累计用量当成本场用量。
- 增加只读“核对结果”和仅限尚未发送阶段的“标记缺席”：须填写理由并确认；发送中、等待回复及已关联 CLI 任务不能改作未发送缺席。保留幂等、阶段顺序与原主持，部分完成明确列出未完成项。
- 区分协作许可与本场已启动状态；配套 external-ai-team Skill 单独显式更新，按当前任务恢复原会议，普通“继续”不会重复开会。开关与 Skill 不唤醒闲置 Codex。
- 复用既有刷新就地更新耗时，不新增定时器、后台服务或聊天动画；动态时钟不导致整张会议卡反复替换。

## 0.1.0-preview.15 — 2026-11-19（已公开预览版）

- 圆桌增加独立会议 ID、两轮阶段和冻结主持；Muse、Codex 的真实发言无需等待 Agy 结束即可保存与展示，既有聊天和官方上下文保留。
- Agy 发言关联真实 CLI 任务，排队与执行分别计时；同一会议阶段重试不重复派单，原始任务与完整回复可追溯。
- 仅在前一轮结束后进入下一轮；缺席、失败、取消、发送待核对分别显示，部分完成不冒充共识；暂停阻止新派发但保留已发任务的真实结果。
- 未开始阶段压缩显示，长派发指令按任务独立收起；会议历史按页读取，摘要接口不传会议正文、不复制整段任务内容。
- 新增精确聊天的 bridge 会议创建、事件同步与查询接口；持久化失败回滚、跨会话隔离和备份恢复均作验证。配套活跃任务 Skill 集成候选单独交接，不覆盖已安装 Skill，不新增后台调度器。
