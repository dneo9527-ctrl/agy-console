# Agy 控制台 · Windows x64 便携版

版本：0.1.0-preview.5（2026-11-15）。适用于 Windows 10 1809 或更新版本、Windows 11，Intel/AMD 64 位。无需安装 Python，不需要管理员权限，不创建开机启动或后台服务。不适用于 32 位 Windows；本包未提供 ARM64 原生运行时。

## 开始使用

1. **先完整解压**到自己的可写目录，例如 `D:\Tools\AgyConsole`。不要直接在 ZIP 中启动，不要放在 Program Files。
2. 首次使用先安装官方 Antigravity CLI。官方页面：<https://antigravity.google/download#antigravity-cli>。官网提供的 Windows PowerShell 命令为：

   ```powershell
   irm https://antigravity.google/cli/install.ps1 | iex
   ```

   此命令只需在 Windows 端执行；本发行包不会自动下载、安装、运行该安装脚本。
3. 双击 **Login-Agy.cmd**，在官方 CLI 的界面中完成一次登录。已有官方 CLI 登录可以跳过。这与 Codex 登录相互独立，每个聊天无须重新登录。此包不含 Mac 的凭据。
4. 双击 **Start-Agy.cmd**，保持启动窗口打开。看到端口和就绪提示后，双击 **打开面板.url**，或访问 <http://127.0.0.1:8765/>。
5. 在页面选择模型并发送任务。首次账号检查可能需要约 15 秒；没有取得额度时显示未知，不会当成额度为零。

关闭启动窗口或在其中按 **Ctrl+C**，会停止服务及它启动的 CLI 进程树，释放后台内存。仅关闭网页不会停止服务。聊天记录和设置保存在包目录的 `data` 文件夹，下次打开继续使用。

官方 CLI 默认安装位置：`%LOCALAPPDATA%\agy\bin\agy.exe`，也支持 PATH 中的 `agy.exe`。自定义安装可先在终端设置 `AGY_BINARY` 为完整 `agy.exe` 路径，再启动。不要把 API 密钥填进这个变量。

## 模型排序与额度候补

- 全局默认模型直接在设置行右侧选择模型与思考档位，修改后自动保存；只有未单独设置的窗口沿用。保存失败会恢复上次保存值并提示。

- **设置 → 额度用完自动候补 → 配置**：默认开启，文字和生图分别保存；勾选候补模型，用每行 ↑↓ 调整编号优先级，可单独调整档位；文字、生图各自保存顺序。
- “恢复默认候选”会恢复默认名单；它不是排序同步按钮。箭头调整顺序不会清除自选名单和档位。
- 当前固定模型还有额度时继续使用它；耗尽后才按序选候补。不同档位共用额度时，不会靠轮换档位绕过额度。
- 额度已知耗尽时，输入框显示“将按排序自动使用…”和候补模型，无需点“改用”。这只是预计，执行前会再次核对；任务记录里的“模型切换”显示实际使用结果。模型菜单和按钮显示同一保存的首选，预计接替仅在次级提示显示。额度圈为共享池余量，不保证某一具体模型可用。
- 运行中只有明确的额度拒绝、且能确认没有输出或工具操作时，最多自动恢复一次。超时、网络错误或已经执行操作时保留结果，供手动继续。不会自动付费、购买额度或切换账号。
- 生图仅在当前选用、历史成功出图或你主动勾选的模型中候补，不能保证所有文字模型能生成图片。

## 系统代理

优先沿用启动终端的 HTTP_PROXY / HTTPS_PROXY 等代理变量。没有设置时，读取当前 Windows 用户已开启的手动系统 HTTP 代理，仅接受本机回环地址（例如 `127.0.0.1:7897`）。不会修改 Windows 设置；本机面板始终直连。

PAC 自动配置、远端代理和带账号密码的代理不会被自动搬进 CLI 环境。遇到这类网络配置，请在启动前设置 CLI 支持的代理环境，或使用自己的 TUN。修改代理后重开启动窗口。

## 与 Codex 协作

此包提供同样的 `app\bridge.py` 固定会话接口。Windows 的 Codex 在当前聊天环境有 `CODEX_THREAD_ID` 时可运行：

```powershell
& 'D:\Tools\AgyConsole\runtime\python.exe' 'D:\Tools\AgyConsole\app\bridge.py' --ensure --title '项目名称'
```

把路径改为实际解压位置。返回 URL 中的 `?codex=...` 是当前聊天的固定入口，根地址只是总览。派发示例：

```powershell
& 'D:\Tools\AgyConsole\runtime\python.exe' 'D:\Tools\AgyConsole\app\bridge.py' --task-file 'D:\Work\task.txt' --out 'D:\Work\review-01' --timeout 600
```

不写 `--model` 会尊重该固定窗口按文字/生图保存的模型与候补设置。每次使用同一聊天的环境 ID，勿借用其他聊天 ID。若 CLI 环境未提供 ID，需要由 Codex 用真实当前聊天 ID 显式传 `--thread-id`，不能按标题猜测。

Windows 的 Codex 仍需配置本机协作 Skill/项目指令来自动调用 bridge。这个发行包不会改写你已有的 Codex 指令；仅打开网页不能唤醒闲置的 Codex，也不会自动把这台 Mac 的全部聊天绑定带过去。显示右侧活动页取决于当前 Codex 的浏览器工具及权限。

可直接复制的首次接入、日常协作、故障排查与继续开发提示词见包内 `Windows-Codex-提示词.txt`；先在 Windows Codex 中打开本包解压目录，再复制对应段落。

## 自检、更新和备份

- **Diagnose.cmd**：检查依赖、官方 CLI、目录和端口；不读取凭据、不调用模型。
- **Self-Test.cmd**：不调用模型。验证双管道读流、模型顺序，以及启动监管进程被终止后测试子进程是否全部退出。
- 端口被占用时拒绝重复启动，不会关闭已有服务或其他人的 CLI。
- Windows 版更新：先关闭原启动窗口，再替换 `app` 等程序文件，保留 `data`，重新打开。为维持关窗清理语义，本版未开放原地重载。
- 页面设置可备份聊天、图片和固定绑定；备份不含官方登录和 CLI 内部上下文。跨电脑恢复面板记录不等于恢复官方会话上下文。
- 本版尚不支持从网页唤起 CC Switch；需要换号时先结束任务、关控制台，在官方 CLI 中完成登录后重开。
- 外部终端的锁文件与进程映射在 Windows 未实现；无法证明的外部活动显示未知，当前面板派发的任务仍有真实排队、进度、回复和历史。

## 验证范围

这是 Windows 便携预览包。已在制作端验证 Python 源码编译、跨平台逻辑回归、双管道读流和 ZIP 内容清单；**未在 Windows 实机执行 Job Object、ConPTY、官方登录和真实模型调用**。包内保留 Windows 自检入口，首次运行请先执行 Diagnose.cmd 和 Self-Test.cmd。不要把 macOS 回归结果视为 Windows 实机验收。

Windows 命令行长度有限，单次输入限约 26000 个 UTF-16 字符；长材料请拆分为同一会话的多轮任务。关闭窗口时最近约一秒尚未落盘的片段可能丢失，已落盘历史保留。

## 来源与文件

`runtime`：官方 CPython Windows 嵌入版，以及 PyPI 的 pywinpty、psutil Windows 轮子；版本、下载链接、SHA-256 见 `THIRD-PARTY.json`，许可证随包保存。

`app`：本项目的 Windows 适配副本；不影响 Mac 上原有服务。`SHA256SUMS.txt` 记录发行文件校验值。

不包含个人账号、聊天历史、图片、项目内容、官方认证目录或 Mac 的任何启动项。首次运行后产生的 `data` 是你的持久数据，请自行备份后再删除。
