Agy Console 已准备好

Windows x64 · 内置 Python，无需管理员权限。这是本机网页控制台，官方 Antigravity CLI 需要你自行安装并登录一次。

  1. 打开官方 CLI 安装页面，按官方 Windows 步骤安装。已有 CLI 可跳过；本包不会自动执行安装脚本。
  2. 从开始菜单的 Agy Console 文件夹打开 Official CLI Login，或双击程序目录里的 Login-Agy.cmd。在官方界面完成本人登录。已有登录可跳过。
  3. 双击桌面 Agy Console 或程序目录里的 Start-Agy.cmd。等待启动窗口显示服务就绪，并保持窗口打开。
  4. 打开面板，或从开始菜单选 Open Panel。关闭网页不会停止服务。
  5. 需要 Codex 自动协作时，从开始菜单选择 Install Codex Skill，或在程序目录双击 Install Codex Skill.cmd。这会安装配套 Skill 并添加默认协作规则，保留你原有的 Codex 指令。重新打开或新建 Codex 聊天后生效。
结束使用：关闭启动窗口或按 Ctrl+C，停止本工具启动的服务和 CLI 子进程。升级或卸载前请先结束任务并关闭该窗口；安装器不会替你强制终止任务。

安装版把聊天数据保存在 %LOCALAPPDATA%\AgyConsole\data；升级和卸载默认保留。便携 ZIP 仍使用自身目录里的 data。两者不会自动合并旧数据；请先用面板的备份功能保留记录。

本次 .8 只提供完整包，不提供程序更新 ZIP。常规程序更新只更新面板程序，不会安装本向导、官方 CLI 或运行时。完整安装版升级请下载新的 setup.exe，先关本工具，再安装到原安装位置。
