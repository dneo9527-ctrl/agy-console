# 隐私与发布边界

源码导出使用明确文件名单；不复制 `data`、`reviews`、图片、账户显示截图、数据库、日志、备份、认证目录、`.env` 或个人配置。当前测试 ID 与账号为合成数据。

运行时会通过官方 CLI 发送使用者提交的任务和相关材料给其服务商。页面保存在本机不表示模型推理完全离线。官方 CLI 管理认证，本项目不要求在聊天中粘贴令牌。

面板使用 127.0.0.1，校验 Host，写接口校验会话令牌与来源。这是浏览器跨站请求防护，不是独立用户登录：页面会把本次令牌提供给本机 bridge，同机能访问该端口的其他进程或用户也可能读取。它不是多用户服务，不应通过公网监听、隧道或反向代理开放；不适合有不受信任本机用户或进程的环境。

面板读取官方 CLI 的会话摘要/可见文字，用于本机活动查看。兼容旧 `ai-assistants/runs` 的导入默认关闭，只有用户显式指定 `--import-legacy-history` 才执行。发布审计不会为了检测秘密而打开制作者的认证目录或真实聊天。

源码、提交历史与安装包分别审计。脚本扫描只能发现有限模式，不能保证不存在所有秘密；扫描报告不输出匹配值。第三方依赖的公开证书若被扫描命中，应核对原始上游归档，不盲目删除。

第三方网站链接仅在使用者主动点击时打开；本工具不代发消息给其他人，不安装后台 watcher，不自动付费或切换账号。

## 多 AI 与圆桌记录

提供方开关和启动策略按真实 Codex 聊天独立保存，离线镜像只含必要偏好与启动元数据。具体正文不进入该镜像。圆桌发言由当前活跃 Codex 从已获准的项目网页实际观察后同步；来源链接和同步标记保留。发言收据与官方 CLI 任务分开保存，不写入 CLI 上下文、不增加该任务的 token 统计。完整面板备份包含这些发言；可移植设置导出不含正文、聊天绑定或登录。开关本身不自动登录、付费或唤醒闲置模型。

在已由使用者另行配置 CodexBark 的 Mac 上，可选本地事件接收器可能把任务最终状态、短聊天标题和本地轮次标识交给该接收器；接收器自行控制通知策略。本源码不携带 Bark 接收地址、密钥或手机配置，也不安装或启用通知服务。
