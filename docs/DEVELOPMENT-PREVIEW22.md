# 0.1.0-preview.22 开发候选验证范围

此版本从已发布 preview.16 整合 .17–.21 与零 CLI 圆桌导出修复；两个平台使用相同通用 Skill。

本地回归和源码适配检查另由交接方提供。最终准确 SHA 的 CI、完整平台包、Windows 原生 install/upgrade/guard/uninstall、匿名重下载与旧资产不变仍待发布流程；不要以本地结果或旧 CI 替代。Windows 源码在其他系统运行不构成 Windows 原生验收。

新增账号同步只读取官方身份和模型，不选择登录账号；CC Switch 入口是 Mac 专用。OpenScience 仍为禁用占位。导出只含面板实际存储记录，图片以原控制台链接引用。自动显现的本机用户确认与宿主可见性指标分别记录，未新增全平台验收。Skill 只作用于活跃 Codex，不唤醒闲置聊天或新增服务。
