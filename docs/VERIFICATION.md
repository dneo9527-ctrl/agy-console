# 验证范围

## 0.1.0-preview.15

开发交接 ZIP 为 197 个冻结源文件，已逐文件核对路径、模式、大小、摘要与 CRC。开发者报告 394 项 Python、34 组 JavaScript，并在 Mac 的真实 Codex/Agy/Muse 项目会话完成两轮提案、互评和 Codex 主持总结 7/7，刷新及同一前台进程重载后记录保留。这是开发端证据，不替代发行验收。

发行候选从公开 preview.13 三方合并，保留数值回环绑定、Windows UTF16/终端/Job 适配、前台启动器和安装框架，新增完全相同的 external-ai-team preview.4 九文件 Skill 双平台副本。公开源码和附件均排除真实数据、日志、私有 adapter、凭据和开发端现场记录。

发行端按最终提交另行检查 Python/JavaScript 回归、7 项发行框架测试、全历史隐私模式审计和四平台 CI（macOS ARM、macOS Intel、Ubuntu、Windows）。Windows 用真实 Inno Setup 安装器覆盖首次安装、公开 .8 升级、运行保护和卸载；临时 Codex home 检查两套 Skill、实际 dispatcher 绑定与原规则保留。最终执行结果及准确 SHA 见对应 Release、Actions 和附件 PLATFORM-VERIFICATION.json。

完整源码 ZIP、Mac/Linux 源码预览、Windows 便携包及独立 Skill 包核对清单、逐文件字节/执行位、摘要、CRC、草稿回下载与公开匿名回下载。preview.8 的稳定 bootstrap 不接受新增模块，必须使用完整包升级，本版不发布 program-only ZIP 或自动更新清单。

## 仍未验收

- Windows/Linux 真实官方登录、模型调用与原生网页协作；所有旧聊天自动加载与跨窗口自动运行。
- 全新机器、旧系统、隔离标记首次打开、Windows SmartScreen；无 Developer ID、公证或 Windows 发布者签名。
- 闲置 Codex 唤醒与后台网页采集不属于本项目功能。会议计划、已发送回执及多模型意见一致都不能代替实际结果或测试。
- Bark Console 接口与 Antigravity.app 原生接入范围分别披露，未据此声称真实模型事件或手机通知实收。

所有发行测试使用合成身份、临时 HOME、假 CLI 与随机回环端口；不读取现用账号或数据。历史版本验证记录保留于其不可变 Release。
