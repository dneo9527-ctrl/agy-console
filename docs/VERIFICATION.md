# 验证范围

## 0.1.0-preview.16

开发交接为 218 文件源码 ZIP，发行方逐一核对摘要、路径、CRC 和执行位；相对公开 preview.15 有 23 路径增量。开发者报告最终合并源 410 项 Python、35 组 JavaScript、7 项发行框架测试及 Mac 真实 Codex/Agy/Muse 两轮加主持总结 7/7。该记录含开发等待，墙钟不是纯模型耗时；Agy 官方已知用量不包含网页未知用量。开发证据不替代发行验收。

基线保留数值回环绑定、前台启动器、Windows PipeSelector/Job/终端/信号/账号保护及禁止原地重载。主程序与 Windows server 分别只合入本轮改动；发布方不以主程序覆盖 Windows 适配。两平台配套副本与独立 external-ai-team preview.5 的九个文件完全一致，原安装器、许可证和脚本保持。

发行端对最终准确提交执行 Python/JavaScript、发行框架、允许列表及可达历史模式审计；多平台 CI 包含 macOS ARM/Intel、Ubuntu 和 Windows。Windows 显式加入新增会议耗时/结果/缺席动作测试，以真实 Inno Setup 安装器检验首次安装、公开 .8 升级、运行保护和卸载。临时 Codex home 验证 Skill 实装、原规则保留、dispatcher 与会议协议；不接触真实账号或模型。

最终执行结果见对应 Release、Actions 和 PLATFORM-VERIFICATION.json。完整源码、Mac/Linux 完整包、Windows 便携包/安装器、独立 Skill 包与校验文件成套交付；先验证草稿下载，再作公开匿名下载及源码 Git blob/执行位核对。不上传截图、会议正文、真实数据、日志、私有适配或依赖目录。

preview.8 必须用完整包升级，本版不发布普通 program-only ZIP 或自动更新清单。Skill 需显式安装，程序更新不会自动安装 Skill。

## 仍未验收

- 宿主自动展开活动页：开发观察为 queued/visibility=false，不代表用户可见展开成功。
- Windows/Linux 真实官方登录、模型调用与网页投递；系统睡眠唤醒；所有旧聊天自动加载。
- 全新机器、旧系统、检疫首开、Windows SmartScreen；无 Developer ID/公证或 Windows 发布者签名。
- 无闲置 Codex 唤醒、后台采集或无限重试；协作许可不等于已经组织会议。真实模型事件与手机实收不由本轮发行验收建立。

所有发行回归使用合成身份、临时 HOME、假 CLI 和随机回环端口。历史验证保留于不可变的历史 Release。
